# 图表承担论证任务

先写清图要回答的问题：方法输出是什么、基线差异在哪、误差随什么变化、哪个约束限制方案。再选图形，不能为了丰富版面堆图。2025 具体样本和页码见 [exemplars/visual-patterns.md](exemplars/visual-patterns.md)。

| 要比较什么 | 合适形式 | 必需信息 |
| --- | --- | --- |
| 实际方案 | 分配表、路径图、甘特图 | 容量、顺序、单位、不可行或未覆盖部分 |
| 目标或误差 | 点图、条形图、箱线/分布图 | 同一测试条件、基线、完整重复波动 |
| 正向拟合与反演 | 观测与拟合曲线、残差子图 | 数据点、同一预测数组、横轴单位和误差尺度 |
| 时间预测 | 历史、预测、区间和误差 | 训练/预测分界、区间含义、评估窗口 |
| 敏感性 | 参数扫描、热图 | 参数范围与单位、其他条件固定、无解区域 |
| 算法过程 | 收敛曲线、决策流程 | 停止条件、迭代或时间单位、真实分支 |

绘图脚本只读结果，不重新调参、修改预测值、剪去不利点或伪造不确定性。在求解阶段生成用于报告与图形的同一数据。拟合曲线与残差必须来自同一预测，图中数字和正文使用同一结果版本。

按出版尺寸设置稳定字号、线宽、颜色和布局；不使用装饰三维、渐变和误导尺度。颜色外再用标记或线型区分。并列图的坐标是否共享由比较任务决定，非共享尺度需明确；不得放大改进而隐藏零点或刻度含义。

输出适宜的 PDF/SVG 和预览 PNG，保留脚本、原数据、图注及图表清单。检查裁切、字号、单位、图例遮挡、颜色可辨性和图注。看过实际渲染才能记录视觉检查；文件存在或像素非空只能证明产出，不等于视觉质量通过。
