# 数学和计算验收

先写检查对象、预期性质、方法、容差及失败动作，再计算。容差来自数据精度、数值误差或题意，不能事后调宽以变成 PASS。

| 检查 | 能支持什么 | 例子与注意 |
| --- | --- | --- |
| 量纲与数量级 | 单位和数量级一致 | 波数与厚度换算、运输成本单位；不能只看数值是否“像真的” |
| 边界与退化 | 模型在已知条件下退化正确 | 零需求零费用；理想情况下的解析解；先确认该性质在约束下成立 |
| 小规模对拍 | 当前实现符合已知或精确实例 | 枚举离散空间、解析解、可靠精确求解器 |
| 独立互验 | 排除共享错误的部分可能 | 不同数学表达或独立算法；同函数换种子不是独立正确性证明 |
| 守恒与题面对账 | 约束、局部真值和附件示例一致 | 质量/概率/流量守恒；逐句输出要求均有落点 |
| 现实合理性 | 适用范围和业务意义可解释 | 参数可识别、方案可执行、预测信息当时可获得 |

不适用写明对象和原因，例如分类问题没有已定义的物理质量守恒；不能凭空造一个守恒检查充数。人工合理性判断待队内完成时保留未核验状态。

## 优化

保存求解器状态、时限、最优值或最好可行值、对偶界和 gap（若可用）。报告 primal 残差、变量域、约束方向。启发式给“当前最好可行解”，只有数学证明或有效求解器证据时称全局最优。非凸局部求解成功不等于全局最优。

验收论文和执行文件中最终采用的变量值。取整、阈值化、分段、单调投影或修复可能改变可行域、目标值与最优性证据；保留处理前后方案，重新核对约束、整数域与目标，更新对应 claims。后处理后的可行解不能沿用原解的最优性结论。线性 LP/MILP 可使用 [最终方案核验器](linear-solutions.md)，其他结构编写与实际模型一致的检查。

## 随机与预测

预先登记种子列表和停止准则，报告全部运行及波动；重复次数随方差、预算与决策用途设定。固定种子只支持复现，不等于稳健性；若要显著性结论，说明检验、独立性、样本与多重比较处理。

按真实预测对象与信息时点选择划分；任务同时要求新个体与未来预测时，同时隔离群组和时间。预处理、筛选、调参、阈值和区间校准仅用允许的训练或验证数据，最终测试不参与选择。核对折内重新拟合、重复观测和指标口径，见 [预测验证](prediction-validation.md)。保留简单基线，报告绝对量和比较；MAPE 在真实值接近零时需改指标或说明处理。

## 验证分层

参数反演检查实际观测能约束哪些参数组合。保存候选点和导数来源，按参数与残差的合理尺度检查 Jacobian 秩和条件数，再按需要做剖面、真值回收和噪声分析；参见 [参数可辨识性](parameter-identifiability.md)。拟合优度、两两相关性、多初值结果接近和局部满秩分别支持不同范围，不能相互替代。

换权重、去模块、扫参数分别是方法敏感性、组件贡献和参数敏感性。它们不能自动替代代码正确性或外部有效性。拟合优度不能证明预测、因果或参数真实。

程序校验通过只说明它覆盖的条件。最后人工检查论文中的条件、单位、图表和解释是否与计算范围一致。只要输入、代码、参数和环境没变且无新疑点，不反复重跑相同检查。
