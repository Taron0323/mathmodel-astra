# 自然、准确的中文数学建模写作

开始前读取实际题面、术语、IDEA、当前结果与正文主源，确认本次是结构起草、结果写作还是保义改写。已有 mathmodel-writing 时由它负责正文，本总控负责证据与阶段依赖。

2025 指定来源的逐篇学习与可追溯规则见 [exemplars/writing-patterns.md](exemplars/writing-patterns.md)。只有已读样本支持的观察才归因于样本文风，以下示例均为本 Skill 的演练改写，不是原论文引文。

| 写作任务 | 具体做法 | 保义例子或边界 |
| --- | --- | --- |
| 摘要 | 用实际问题对应的模型、动作和答案组织，突出最终交付和关键检验 | 有数值写值和单位；策略题可写策略及可实施条件，不硬塞一个数字 |
| 问题分析 | 说明问题特征如何决定变量、关系与约束 | “需求必须全部满足，故将各点收货量与需求量设为相等。” |
| 假设 | 说明简化的对象、必要性、受影响结果和可检验范围 | 不写“所有参数准确无误”，应交代测量或估计误差 |
| 建模 | 先定义现实量及数学关系，再命名模型；公式周围解释符号和适用条件 | 结构清楚时可直接写标准模型名称，不设无条件禁令 |
| 求解 | 解释算法与结构、规模的匹配，给停止条件和求解状态 | 多初值局部最小二乘写搜索范围及最好残差，不称“保证全局最优” |
| 结果 | 从权威 CSV 读取数值，给比较条件和实际含义 | “相同供需约束下，费用由 43 降至 25，减少 18。” |
| 检验 | 写检验对象、方法、容差及观测结果 | “独立枚举的最优值同为 25；约束残差不超过预设容差。” |
| 评价 | 评价已展示的优势和实际影响结论的限制 | “本例采用线性费用，未覆盖拥堵导致的非线性运输成本。” |

## 去冗余防御

先判断限定语是否改变命题。删去“需要强调的是，我们并非试图证明一种普适方法，而仅希望……”之类对假想质疑的长篇回应；保留实际信息，例如“该结论适用于线性费用和给定供需约束”。有统计或数学作用的“在独立同分布假设下”“几乎处处”“在误差范围内”等不能机械删除。

反例：“虽然本模型可能存在不足，但总体效果较好，能够在一定程度上显著提升效率。”

演练改写：“在本合成实例中，模型费用比可行基线低 41.86%；该比较使用相同供需约束。”如正文需要讨论现实条件，再具体说明哪项条件未验证，避免重复堆限定。

避免空泛赞词、无证据显著性、流水账、重复背景、装饰性术语和每段相同的“首先—其次—最后”。过渡词本身不等于 AI 语言，只有不承载逻辑才删。不为了检测分数制造语病、编实验经历或隐瞒 AI 使用。

## 改写验收

对照改写前后：变量和量纲相同、条件与结论强度相同、正负方向和数字一致、失败结果未被隐藏、引用仍支持对应句子。数字冲突回到结果文件修正文稿，不能选择“看起来更好”的数值。正文改动通常不触发求解重跑；公式语义改变则重查相应数学和计算证据。

明确表中数字是显示精度还是执行精度。表格仅截取小数时写明约束检验用未舍入值；实际执行也按该位数取整时，检验并报告取整后的方案和费用。演练例子：“连续松弛费用为 1.7，取整后的覆盖量为 3，低于要求的 4；整数模型给出费用 2.2 的可行方案。”这比“取整误差较小，基本不影响结果”更准确。最优性另有枚举、界或求解器证明时再增加对应结论。
