# 参数反演与可辨识性

用于从观测反推机理参数、非线性拟合、多角度或多条件联合反演。先明确观测函数、误差模型、参数坐标与允许范围，再判断数据能约束哪些量。

## 区分三个问题

| 问题 | 有效证据 | 对下一步的影响 |
| --- | --- | --- |
| 参数是否在模型结构上唯一 | 不变变换、等价参数族、解析或符号分析 | 若只出现参数组合，改报该组合或补充能打破等价关系的观测 |
| 当前点的一阶信息是否充分 | 合理缩放后 Jacobian 的数值秩、奇异值与方向 | 检查零灵敏度、参数耦合、导数实现和退化点 |
| 有限且含噪的数据能否精确估计 | 参数剖面、适当重采样、区间、噪声和模型扰动 | 缩小结论精度、调整观测条件或引入有来源的外部信息 |

局部秩亏说明该点的一阶信息不足，不自动证明结构性不可辨识。例如 $y=\theta^3$ 在 $\theta=0$ 的导数为零，但映射仍一一对应。满列秩也不保证区间足够窄或排除远处的其他解。

## 缩放与导数

从实际残差函数导出 $J_{ij}=\partial r_i/\partial\theta_j$。在运行记录中保存模型代码、候选点、参数坐标与单位、数据版本、导数来源和差分步长对照。使用自动或解析导数时，仍可用少量方向差分核对符号和量级。

设参数参考变化尺度为 $s_{\theta, j}>0$，残差尺度为 $s_{r, i}>0$，诊断矩阵为

$$J_* = \operatorname{diag}(s_r^{-1})J\operatorname{diag}(s_\theta).$$

尺度来自物理变化范围、测量精度或事先规定的参考量，不直接取可能为零的参数估计值。参数改用另一单位时同步转换 Jacobian 和参考尺度，诊断应保持一致。对数参数采用对应坐标的导数，不能把对原参数的导数直接当作对数坐标导数。

残差尺度可表示参考单位，或独立误差的标准差，二者分别记录。有相关误差时，先按明确的协方差模型白化残差和 Jacobian；单独除以各自标准差不能消除相关性。由稳健损失修正的求解器 Jacobian 也不能未经核对直接当作原始观测误差模型的信息矩阵。

## 如何解释诊断

用 SVD 检查奇异值谱和右奇异向量。记录相对秩容差及其来源；机器精度阈值只用于数值秩判断，不是噪声下可接受估计精度的阈值。弱方向应转换回对应参数坐标，说明哪些参数可以彼此补偿。

两两灵敏度列相似度与总体矩阵秩是不同对象。三个参数可能存在整体线性依赖，而每对列的夹角余弦都低于常用阈值；这些余弦也不是参数估计协方差的相关系数。不能用一张相关图替代整体诊断。

若存在耦合，先检查可识别的参数组合，再比较有物理依据的联合观测、额外测量或参数固定方案。共享参数来自同一试样等实际条件；使用相同数据和相同假设的两种算法不能排除共同模型偏差。边界、正则项或先验可能选出唯一解，应说明它们贡献了哪些信息。

剖面分析固定一个目标参数后重新优化其余参数，保留每点求解状态、多初值分支与边界命中情况。区间阈值需要误差分布及适用近似，不能将任意损失增量叫作 95% 置信区间。合成真值回收应覆盖相关参数范围和噪声条件，单个种子的回收不能证明真实数据可辨识。

## 可运行局部诊断

`scripts/diagnose_identifiability.py` 使用 NumPy SVD，读取一份实际导出的 Jacobian JSON。它不求解模型或生成统计区间。输入字段示例如下，为独立构造的线性反例：

```json
{
  "parameter_names": ["a", "b", "c"],
  "jacobian": [[1, 1, 2], [1, -1, 0], [-1, 1, 0], [-1, -1, -2]],
  "parameter_scales": [1, 1, 1],
  "residual_scales": [1, 1, 1, 1],
  "residual_scale_kind": "reference"
}
```

```sh
python scripts/diagnose_identifiability.py --input jacobian.json --output results/sensitivity.json
```

`residual_scale_kind` 可用 `reference` 或 `independent_noise_sd`；可选 `relative_rank_tolerance` 需不小于当前矩阵的 float64 精度阈值并小于 1。默认阈值为最大矩阵维数乘机器精度。脚本保护输入和硬链接别名，输出输入与实现哈希、尺度、奇异值、数值秩、条件数和未确定的一阶方向；满列秩时也给出最弱灵敏度方向，帮助定位需要补充信息的参数组合。方向的符号和重根子空间中的基可不唯一。诊断完成状态为 `DIAGNOSED`，秩状态另列，不把秩亏误写成脚本失败或把满秩写成科学验收通过。

本例对应 $y=(a+c)u+(b+c)v$，第三列是前两列之和。两两列余弦的最大绝对值约为 0.707，数值秩仍为 2；$(a, b, c)$ 与 $(a+t, b+t, c-t)$ 产生相同预测。应报告可识别组合 $a+c$ 与 $b+c$，或增加能区分各参数的观测。这里的结构性结论来自显式等价参数族。

写作可据此表述：“三组拟合得到相同预测，但单独的参数值不同。观测仅约束 $a+c$ 和 $b+c$，后续分析采用这两个组合。”不要改成“拟合优度很高，因此三个参数均可靠”。
