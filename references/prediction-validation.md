# 让预测验证对应实际任务

用于预测、分类、检测、生存分析及含重复观测的数据。先确定要预测谁、预测哪个时点，以及届时能使用哪些信息，再选择划分和算法。

## 明确预测对象

在项目协议中登记记录单位、独立个体或群组、目标人群、预测时点、预测跨度、标签形成窗口和各特征的可用时点。个体可以是患者、设备、学校或地点。行数与独立个体数分别统计，重复测量不能增加同等数量的独立样本。

| 实际目标 | 外层评估划分 | 要核对的证据 |
| --- | --- | --- |
| 未见过的新个体 | 个体或相应群组隔离，例如 GroupKFold | 训练与测试个体交集为空，各折个体数和类别分布 |
| 已知个体的未来观测 | 按预测时点向前滚动或截断；允许使用届时已有的个体历史 | 训练标签在拟合时已形成，特征窗口截至预测时点，同一个体未来记录未回流 |
| 未来出现的新个体 | 同时约束个体隔离和时间顺序 | 两种条件都满足；单独 GroupKFold 不保证时间隔离 |
| 同分布的独立记录 | 根据任务采用随机或分层划分 | 独立性依据、重复或近重复检查、部署分布与特征可用性 |

未来标签窗口跨过训练截止、相邻时间窗共享原始观测、同源切片或派生样本跨折时，按实际重叠范围留出间隔或合并划分单元。间隔长度由采样、标签和信息形成方式确定。随机划分是否适用取决于任务，不能只凭方法名称判断。

## 每折真正重新训练

在各折训练数据上拟合缺失填补、标准化、特征筛选和模型；采用 Pipeline 等现有工具，保存行索引及拟合样本量。数据体检可以检查完整输入的结构，但用于预测的统计量应服从训练边界。

调参、阈值选择和概率或区间校准使用外层训练集内部的验证数据，内部划分继续遵守个体与时间约束。最终测试集保持独立。Stacking 的训练特征来自内层折外预测，再对外层留出数据评估；把已在全数据拟合的模型拿到分折索引上预测，不构成样本外交叉验证。

## 对账与报告

验收至少覆盖以下与任务相关的事实：

- 各折训练与测试行不重叠、索引没有重复；单次 K 折时每行恰好被留出一次，重复交叉验证按重复编号分别核对。
- 分组任务的实际个体交集满足协议；时间任务的特征、标签和拟合截止满足协议，不能仅检查一列日期排序。
- 预处理与模型的拟合范围对应训练索引；每条预测关联行、个体、折号和真实标签，指标从保存的预测独立复算。
- 比较模型与基线使用相同划分和指标。明确按记录加权还是按个体等权；个体观测次数不同时，两者回答的问题不同。
- 分类按错误代价报告逐类指标与支持数；稀少类别或单一类别折如实记录，不能改划分只为提高分数。区间估计保留个体或时间相关性，例如按个体重采样或时间块重采样；折间标准差不直接当作独立样本置信区间。

预测结果再进入优化决策时，保留中间预测及误差传播，检验策略对预测偏差的敏感性。训练拟合、内部回测与外部验证的结果分开说明。

## 可运行的重复观测反例

`scripts/grouped_prediction_demo.py` 生成 256 个个体，每个个体四条完全相同的特征记录；标签按个体独立随机生成，与特征独立。模型为每折重新拟合的 StandardScaler 与单近邻分类器，基线为训练折的多数类。个体 ID 只参与划分，不作为预测特征。

脚本比较按记录随机五折与按个体隔离五折。前者常可从训练集找到相同个体的重复记录，后者测试个体均未出现过。图同时展示准确率、基线和每折的个体交集，直接说明高分来自何种评价条件。它使用预先登记的固定种子验证这一反例，不构成多种子稳健性评估；也不保证真实数据采用分组划分后必然降分。

在发布仓库根目录运行：

```sh
python -m pip install -r requirements-prediction.txt
python scripts/grouped_prediction_demo.py run --workspace practice/grouped-prediction
python scripts/grouped_prediction_demo.py render --workspace practice/grouped-prediction
```

个人安装版可在项目已有环境补齐 numpy、scikit-learn、matplotlib 后，将命令中的脚本路径替换为实际 Skill 路径。`run` 要求新目录；`render` 只读取已通过完整检查且输入、结果和代码哈希匹配的证据，不重新训练。输出包含输入与协议、折索引、每条预测、指标 CSV、验证记录、PNG/SVG 和中文说明。修改数值、缺少验证项或使用旧代码记录时拒绝生成图文。验证记录的哈希用于对账，不认证第三方记录的真实性。

本例体现了 [C132 学习卡](exemplars/cards/C132.md) 中记录粒度、个体粒度与决策时点的区别。数据为独立构造的合成数据，未复现该论文的模型、数值或诊疗结论。
