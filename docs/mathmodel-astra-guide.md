# mathmodel-astra 使用总稿

`mathmodel-astra` 是面向 CUMCM 及公开题演练的科研辅助总控 Skill。它把题面、数据、数学模型、求解、验证、图表、论文和交付连接成可追溯流程。它不替代参赛队的核心建模、分析、人工审查或账号操作，也不在正式题面到达前生成正式赛题答案。

## 适用边界

- 准备阶段：整理规则、模板、提示词、题型卡、公开论文和合成演练。
- 正式阶段：收到题面后逐句建需求表，锁定数据和规则，再进入建模与交付。
- 演练结果全部放在 `practice/`，并标明合成或历史题来源。
- 湖南、江苏、河北分别维护资料；每支队伍运行时选择一个生效赛区，再叠加全国规则。
- 需要密码或强制登录的网页直接跳过，记录 `PASSWORD_REQUIRED_SKIPPED`，不索取或尝试密码。

## Astra Max 与 Ultra

Max 用于资料提取、数据体检、基线实现、常规求解、绘图和保义改写。Ultra 用于目标函数或核心假设存在分歧、参数不可辨识、预测泄漏、约束冲突、非凸结果或最终数学审查的场景。档位由客户端实际配置决定；提示词不能切换档位。运行记录保存模型、档位、时间、命令、输入/代码/参数哈希和输出，无法读取时写 `UNVERIFIED`。

先用少量预算审查路线，保留可交付基线；Ultra 形成决策或发现证据缺口后结束，回到 Max 执行已确定的计算和修复。Max/Ultra 的分工是工作策略，不是效果对比结论。

## 全流程

1. **接收**：保存题面和附件原件，计算 SHA-256，逐句记录原文、页码、输出形式和稳定 ID。
2. **体检**：统计类型、单位、缺失、重复、异常和数量级；清洗规则可重现，原始数据只读。
3. **抽象**：为每问定义变量、单位、目标、约束、可观测输入、输出和真实依赖；比较数学结构后再选算法。
4. **试跑**：实现可解释基线和最小实例，登记时间盒、失败触发、兜底路线和停止条件。
5. **求解**：输出 CSV、运行元数据、日志、求解状态和代码/数据/参数哈希。连续松弛、取整、投影、修复后的最终方案重新验收。
6. **验证**：按题目选择量纲量级、边界退化、小规模对拍、独立互验、守恒、题面对账、敏感性和现实合理性检查。启发式结果写“当前最好可行解”，有证明或有效界才写“全局最优”。
7. **图表**：先定义图要回答的问题；绘图只读结果，不调参或修饰数据。保存 PDF/SVG、预览 PNG、脚本、图注和生成记录，并核对图片与数值证据的哈希关联。
8. **写作**：论文以 `paper/latex/main.tex` 为主源，从权威结果文件生成摘要、表格和图注。直接说明变量、方法、数字、检验和适用范围，删去假想审稿回应和空泛防御语句。
9. **交付**：逐项对账题面、结果、图表、引用、AI 使用详情、格式和大小；人工审查、哈希提交、账号签名和实际上传分别记录，不能由脚本虚报完成。

## 题型路由

- 优化决策：先定变量域和可行域；用 LP/MILP/NLP 或多目标方法，核对约束残差和小规模精确解。
- 机理与反演：先分正向模拟和参数反演；报告参数组合的可辨识性，不能由小残差推出单参数唯一。
- 预测与分类：先确定预测对象、时点和可用信息，再按个体、时间或两者划分；每折重新拟合预处理、特征筛选和调参。
- 综合评价：明确指标方向、尺度和权重来源；权重扰动只能说明敏感性。
- 网络与空间：定义节点、边、方向、容量和距离；检查连通性、流守恒和小图对拍。

预测演练专门区分记录随机划分与个体隔离划分，防止重复观测泄漏。参数反演演练用缩放 Jacobian/SVD 报告数值秩、条件数、弱方向，并区分结构唯一性、局部一阶信息和含噪估计精度。

## 2025 论文学习

中国大学生在线公开目录的样本显示，优秀论文常把自然语言交付转成变量、量词、目标和约束；保留简单基线；按真实中间结果组织各问；让结果表、图和正文读取同一数据版本。A 类状态/集合建模、B 类机理反演、C 类重复测量与预测分类提供了可迁移的结构。样本也暴露出目标定义不一致、绘图预测与优化预测不一致、全量训练后分份预测和校准集冒充外部验证等问题。

这些结论来自公开展示样本的提炼，不是全体获奖论文的统计规律。只迁移建模逻辑和表达方式，不复制原文句式、参数、数据处理或模型复杂度；作者报告、当前分析和迁移建议分开记录。未复现论文代码和数值，不称为本项目验证。

## 证据与目录

项目常用入口为 `paper/CONTEXT.md`、`paper/IDEA.md`、`paper/REQ.md`、`paper/STATUS.md` 和 `paper/HANDOFF.md`。证据合同至少关联需求、参数、结论、代码、运行、结果、图表、验证记录和人工审查。状态使用 `PLANNED`、`RUNNING`、`COMPUTED`、`AI_VERIFIED`、`HUMAN_VERIFIED`、`BLOCKED`、`NOT_APPLICABLE`，不把它们压成一个 PASS。

发布仓库中的可运行演练示例：

```sh
python scripts/grouped_prediction_demo.py run --workspace practice/grouped-prediction
python scripts/grouped_prediction_demo.py render --workspace practice/grouped-prediction
python scripts/diagnose_identifiability.py --input jacobian.json --output results/sensitivity.json
```

安装和验证以宿主环境为准；Skill 只携带必要参考、脚本和范例卡，不上传题面、原始论文、演练私有日志或本机绝对路径。
